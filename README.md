# neupsipro-Movil
Se deben de instalar las siguientes extensiones para el correcto funcionamiento de la aplicación:

_npm install --save-dev husky_

_npx husky init_

_npm install --save-dev lint-staged_

_npm install --save-dev @commitlint/config-conventional @commitlint/cli_

_instalar el plugin de Ktlint directamente desde Android Studio_
